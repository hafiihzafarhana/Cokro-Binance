
# Cokro Binance

A system that helps track and analyze interesting coins on Binance. It provides real-time market data, historical candlestick information, and allows exporting data to CSV for further analysis. This system is designed for crypto traders, analysts, and enthusiasts who want an easy way to monitor market trends and make informed trading decisions.
